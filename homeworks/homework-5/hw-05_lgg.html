Question 1

Jeffrey’s (1961) suggested a default rule for generating a prior distribution of a parameter \(\theta\) in a sampling model \(p(y \mid \theta).\) Jeffreys’ prior is given by \[p_J(\theta) \propto \sqrt{I(\theta)},\] where \[I(\theta) = - E\left[ \frac{\partial^2 \log p(Y \mid \theta)}{\partial \theta^2} \mid \theta \right] \] is the Fisher information.

Part A

Let \(Y \sim \text{Binomial}(n,\theta).\) Show that \(p_J(\theta) \propto Beta(1/2,1/2).\)

We have that \[p_J(\theta) \propto \sqrt{I(\theta)},\]

where \[I(\theta) = - E\left[ \frac{\partial^2 \log p(Y \mid \theta)}{\partial \theta^2} \mid \theta \right] \] is the Fisher information. We want to show that \(p_J(\theta) \propto Beta(1/2,1/2).\) Let \(Y \sim \text{Binomial}(n,\theta)\), so we have \(p(Y|\theta) = {n \choose y} \theta^y*(1-\theta)^{n-y}\) First, we will simplify \(\frac{\partial^2}{\partial \theta^2} \log(p(Y|\theta))\):

\[ \begin{align} \frac{\partial^2}{\partial \theta^2} \log(p(Y|\theta)) &= \frac{\partial^2}{\partial \theta^2} \log[{n \choose y} \theta^y*(1-\theta)^{n-y}]\\ &= \frac{\partial^2}{\partial \theta^2} \log[{n \choose y}]+y*\log[\theta]+(n-y)\log[(1-\theta)]\\ &=\frac{\partial}{\partial \theta} \left( \frac{\partial}{\partial \theta} \left( \log[{n \choose y}]+y*\log[\theta]+(n-y)\log[(1-\theta)]\right)\right)\\ &=\frac{\partial}{\partial \theta}\left( y*\frac{1}{\theta}+(n-y)\frac{1}{(1-\theta)}\right)\\ &= -y*\frac{1}{\theta^2}-(n-y)\frac{1}{(1-\theta)^2}. \end{align} \]

Then, taking the expectation of the simplified expression yields

\[ \begin{align} \mathbf{E}[-y*\frac{1}{\theta^2}-(n-y)\frac{1}{(1-\theta)^2}] &= - \frac{1}{\theta^2}\mathbf{E}[y]-\frac{1}{(1-\theta)^2}\mathbf{E}[(n-y)]]\\ &= - \frac{1}{\theta^2}\mathbf{E}[y]-\frac{1}{(1-\theta)^2}(n-\mathbf{E}[y])\\ \end{align} \]

Since \(Y\) is sampled from a binomial distribution, we know \(\mathbf{E} = n*\theta\). Observe

\[ \begin{align} - \frac{1}{\theta^2}\mathbf{E}[y]-\frac{1}{(1-\theta)^2}(n-\mathbf{E}[y]) &= - \frac{1}{\theta^2}*(n\theta)-\frac{1}{(1-\theta)^2}(n-(n\theta))\\ &=-\frac{n}{\theta}-\frac{n(1-\theta)}{(1-\theta)^2}\\ &=-\frac{n}{\theta}-\frac{n(1-\theta)}{(1-\theta)^2}\\ &= -\frac{n}{\theta}-\frac{n}{(1-\theta)}\\ &= -\frac{n(1-\theta)}{\theta*(1-\theta)}-\frac{n*\theta}{\theta*(1-\theta)}\\ &= -\frac{-n+n*\theta-n*\theta}{\theta*(1-\theta)}\\ &= -\frac{-n}{\theta*(1-\theta)}\\ &\propto \theta^{-1/2}*(1-\theta)^{-1/2} \\ &=Beta(1/2, 1/2). \end{align} \]

Therefore, \(\boxed{p_J(\theta) \propto Beta(1/2,1/2)}.\)

Part B

Re-parameterize the model in part a such that \(\psi= \log[\theta/(1-\theta)].\) This implies that \(p(y \mid \psi) = {n \choose y} e^{\psi y} (1 + e^{\psi})^{-n}.\) Show that \[p_J(\psi) \propto \frac{n^{1/2}e^{\psi/2}}{1+ e^{\psi}} \propto \frac{e^{\psi/2}}{1+ e^{\psi}}.\]

Re-parameterizing the model in part a such that \(\psi= \log[\theta/(1-\theta)]\) now gives \(p(y|\psi) = {n \choose y}e^{\psi y}*(1+e^{\psi})^{-n}\). Observe

\[ \begin{align} p_J(\psi) \propto \sqrt{I(\psi)} &= \sqrt{-\mathbf{E}\left[ \frac{\partial^2 \log p(Y \mid \psi)}{\partial \psi^2} \mid \psi \right]}. \end{align} \]

First, consider the following:

\[ \begin{aligned} \frac{\partial^2 \log p(y \mid \psi)}{\partial \psi^2} &= \frac{\partial^2}{\partial \psi^2} \log\left(\binom{n}{y}e^{\psi y}(1+e^\psi)^{-n}\right)\\ &= \frac{\partial^2}{\partial \psi^2} \left[ \log\left(\binom{n}{y}\right) + \psi y - n\log(1+e^\psi) \right]\\ &= \frac{\partial}{\partial \psi} \left[ \frac{\partial}{\partial \psi} \log\left(\binom{n}{y}\right) + y - n\frac{e^\psi}{1+e^\psi} \right]\\ &= \frac{\partial}{\partial \psi} \left[ y - n e^\psi(1+e^\psi)^{-1} \right]\\ &= -n e^\psi(1+e^\psi)^{-1} + n e^{2\psi}(1+e^\psi)^{-2}\\ &=-ne^\psi(1+e^\psi)^{-1}[1-e^\psi(1+e^\psi)^{-1}]\\ &=-ne^\psi(1+e^\psi)^{-1}[\frac{(1+e^\psi)-e^\psi}{(1+e^\psi)}]\\ &=-ne^\psi(1+e^\psi)^{-1}[\frac{1}{(1+e^\psi)}]\\ &=-\frac{ne^\psi}{(1+e^\psi)^2}\\ \end{aligned} \]

Now, substituting the above expression into \[ \begin{align} p_J(\psi) \propto \sqrt{I(\psi)} &= \sqrt{-\mathbf{E}\left[ \frac{\partial^2 \log p(Y \mid \psi)}{\partial \psi^2} \mid \psi \right]}. \end{align} \]

yields the following:

\[ \begin{align} \sqrt{-\mathbf{E}\left[ \frac{\partial^2 \log p(Y \mid \psi)}{\partial \psi^2} \mid \psi \right]} &= \sqrt{-\mathbf{E}\left[-\frac{ne^\psi}{(1+e^\psi)^2}\right]}\\ &= \frac{n^{1/2}e^{\psi/2}}{1+e^\psi} \end{align} \]

Therefore, we have \[p_J(\psi) \propto \frac{n^{1/2}e^{\psi/2}}{1+ e^{\psi}} \propto \frac{e^{\psi/2}}{1+ e^{\psi}}.\]

\[ \begin{align} p_J(h(\psi)) = p_J(\frac {e^\psi}{1+e\psi}) &\propto \left( \frac {e^\psi}{1+e\psi}\right)^{-1/2} * \left( 1- \frac {e^\psi}{1+e\psi}\right)^{-1/2}\\ &=\frac{1+e^\psi}{e^{\psi/2}}. \end{align} \]

Thus, we obtained \[ \begin{aligned} p_J(\psi) &= p_J(h(\psi)) \times \left|\frac{dh}{d\psi}\right|\\ &= \left(\frac{1+e^\psi}{e^{\psi/2}}\right) \left(\frac{e^\psi}{(1+e^\psi)^2}\right)\\ &= \frac{e^{\psi/2}}{1+e^\psi}. \end{aligned} \]

This is the same density we derived in part b) of this exercise, as desired.

x <- seq(0, 1, 10^-2)
fx <- function(x) sin(pi * x)^2
sim_fun <- function(f, envelope = "unif", par1 = 0, par2 = 1, n = 10^2, plot = TRUE){
  
  r_envelope <- match.fun(paste0("r", envelope))
  d_envelope <- match.fun(paste0("d", envelope))
  proposal <- r_envelope(n, par1, par2)
  density_ratio <- f(proposal) / d_envelope(proposal, par1, par2)
  samples <- proposal[runif(n) < density_ratio]
  acceptance_ratio <- length(samples) / n
  if (plot) {
    hist(samples, probability = TRUE, 
         main = paste0("Histogram of ", 
                       n, " samples from ", 
                       envelope, "(", par1, ",", par2,
                       ").\n Acceptance ratio: ",
                       round(acceptance_ratio,2)), 
         cex.main = 0.75)
  }
  list(x = samples, acceptance_ratio = acceptance_ratio)
}
par(mfrow = c(2,2), mar = rep(4, 4))
