# Samples from a truncated gamma with
# truncation (t, infty), shape a, and rate b
# Input: t,a,b
# Output: truncated Gamma(a,b)
sampleTrunGamma <- function(t, a, b){
  p0 <- pgamma(t, shape = a, rate = b)
  # Use the modification of the inverse CD method
  x <- runif(1, min = p0, max = 1)
  y <- qgamma(x, shape = a, rate = b)
  return(y)
}
# Gibbs sampler
# z is the fully observe data
# c is censored data
# n.iter is number of iterations
# init.theta and init.miss are initial values for sampler
# r,a, and b are fixed parameters
# burnin is number of iterations to use as burnin
sampleGibbs <- 
  function(z, c, n.iter, init.theta, init.miss, r, a, b, burnin = 1){
  z.sum <- sum(z); m <- length(c); n <- length(z) + m
  miss.vals <- init.miss 
  res <- matrix(NA, nrow = n.iter, ncol = 1 + m)
  for (i in 1:n.iter){
    var.sum <- z.sum + sum(miss.vals)
    theta <- rgamma(1, shape = a + n*r, rate = b + var.sum)
    miss.vals <- sapply(c, function(x) {sampleTrunGamma(x, r, theta)})
    res[i,] <- c(theta, miss.vals)
  } 
  return(res[burnin:n.iter,])
}

Trace plots may suggest convergence of the sampler when there appears to be good mixing between the sequences of samples and should ideally appear as “noise” or a “bar code” type appearance. When we change either \(a\) or \(b\), the posterior densities change in both cases. When we change \(b\) from 1 to 100, the prior favors smaller values of the rate parameter \(\theta\) (posterior mean decreases) and the posterior means of the censored values increase relative to Part C. When we increase \(a\) from 1 to 100, the opposite occurs: prior favors larger values of the rate parameter \(\theta\) (posterior mean increases) and the posterior means of the censored values decrease relative to Part C. The shape of the density for theta remains the same in both cases, but the posterior densities for the censored values become less skewed when we increase \(b\) and more skewed when we increase \(a\). This occurs because the expected lifetime under the Gamma model is \(r/\theta\). The observed values are also constrained to exceed their respective censoring times.
